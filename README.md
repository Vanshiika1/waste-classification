# AI Waste Classification System

An AI-based project that classifies waste images into different categories using Machine Learning / Deep Learning.

## Project Goal

The goal of this project is to automatically identify the type of waste from an uploaded image and classify it into the appropriate category.

## Planned Features

- Upload a waste image
- Classify the waste using an AI model
- Display the predicted category
- Simple and user-friendly interface

## Technologies

- Python
- Machine Learning / Deep Learning
- TensorFlow / Keras
- Computer Vision
