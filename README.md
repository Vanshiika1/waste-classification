# ♻️ AI Waste Classification

An AI-based image classification project that identifies different types of waste from images using Machine Learning / Deep Learning.

## 🎯 Project Objective

The goal of this project is to automatically classify waste into different categories using an image classification model.

This can help support better waste segregation and recycling.

## 🗂️ Dataset

This project uses the **TrashNet dataset**.

The dataset contains images belonging to different waste categories such as:

- Cardboard
- Glass
- Metal
- Paper
- Plastic
- Trash
